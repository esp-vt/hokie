\section{Related Work \& Architectural Taxonomy}
\label{sec:related_work}

\paragraph{1. The Transformer Bottleneck \& Softmax Pathology.}
Since the introduction of the Transformer \citep{vaswani2017attention}, scaling self-attention across large-scale pretraining corpora has defined modern NLP. 
However, standard multi-head attention incurs quadratic computational complexity $\mathcal{O}(T^2)$ during pretraining and linear $\mathcal{O}(T)$ Key-Value (KV) cache memory growth during autoregressive generation. 
While Linear Attention variants \citep{katharopoulos2020transformers} and low-rank KV compression techniques (e.g., DeepSeek Multi-Head Latent Attention; MLA \citep{deepseek2024v3}) reduce per-token footprint, they remain fundamentally anchored to the historical sequence length $T$ and retain full pairwise connectivity. 
Crucially, as proven in Theorem~\ref{thm:snr}, the strictly positive normalization kernel ($\exp(\mathbf{q}\mathbf{k}^\top/\sqrt{d}) > 0$) renders Transformers architecturally incapable of active forgetting, diluting attention entropy across obsolete distractor tokens and causing catastrophic context decay in multi-turn conversations.

\paragraph{2. Selective State Space Models \& Linear Recurrent Hybrid Backbones.}
To overcome the $\mathcal{O}(T)$ memory wall, structured State Space Models (SSMs) and linear RNNs—including S4 \citep{gu2022efficiently}, S5 \citep{smith2022simplified}, H3 \citep{fu2022hungry}, Mamba \citep{gu2023mamba}, Mamba-2 \citep{dao2024transformers}, RWKV-6 \citep{peng2023rwkv}, and xLSTM \citep{beck2024xlstm}—have emerged as linear-time alternatives. 
By parameterizing continuous-time dynamical systems $\mathbf{h}'(t) = \mathbf{A}\mathbf{h}(t) + \mathbf{B}\mathbf{x}(t)$ with selective input-dependent discretization ($\Delta_t, \mathbf{B}_t, \mathbf{C}_t$), these models compress past context into an $\mathcal{O}(1)$ recurrent state. 
Hybrid architectures such as Jamba \citep{lieber2024jamba} interleave Transformer attention layers with Mamba blocks. 
However, existing SSMs operate as \textbf{passive, 1-lane deterministic signal filters with uniform exponential decay}. 
Because all state coordinates decay uniformly ($\mathbf{A}_t = \exp(-\Delta_t \mathbf{A})$), passive SSMs suffer from severe memory amnesia on persistent system instructions while retaining noisy scratchpad artifacts. 
\textsc{Hokie-LM} departs from existing SSMs through the Cognitive Active Forgetting Engine (CAFE), which partitions state memory into three dedicated functional lifetime tiers ($\boldsymbol{\Omega}$) with decoupled active eviction ($E_t$) and exact subspace nullification ($\mathbf{P}_\perp$).

\paragraph{3. Generative World Models \& Discrete-Continuous Latent Dynamics.}
In model-based reinforcement learning, agents navigate complex environments by learning internal generative world models \citep{ha2018world}. 
Recurrent State-Space Models (RSSM) such as Dreamer \citep{hafner2023mastering,hafner2024dreamerv3} model transition dynamics via coupled continuous deterministic hidden states and discrete categorical stochastic variables ($z_t \in \Delta^{N \times K}$), optimizing policies purely through internal imagination. 
Similarly, Yann LeCun's Joint Embedding Predictive Architecture (JEPA) \citep{lecun2022path} advocates predicting abstract representations in latent space rather than reconstructing surface-level pixels or tokens. 
While world models have demonstrated extraordinary sample efficiency in robotics and visual domains, adapting discrete-continuous RSSM dynamics as an end-to-end foundation language architecture has remained an open challenge. 
\textsc{Hokie-LM} bridges this fundamental divide by treating natural language tokens as environmental observations and actions, formulating language modeling as world state simulation.

\paragraph{4. Deliberative Reasoning: Verbal Chain-of-Thought vs. Latent Mental Simulation.}
To achieve complex multi-hop deductive reasoning, recent frontier models (e.g., Chain-of-Thought \citep{wei2022chain}, Tree-of-Thoughts \citep{yao2023tree}, OpenAI o1, DeepSeek-R1 \citep{deepseek2025r1}) prompt architectures to emit extensive natural language reasoning traces (Verbal CoT). 
While effective, Verbal CoT incurs immense computational overhead by projecting every intermediate thinking step onto the full vocabulary matrix $\mathbf{W}_{\text{head}} \in \mathbb{R}^{V \times d}$, multiplying generation FLOPs by $15\times \sim 350\times$ and introducing cascading token hallucination risks. 
Latent reasoning approaches such as Quiet-STaR \citep{zelikman2024quietstar} and Coconut \citep{hao2024training} explore continuous thought embeddings within Transformer attention. 
In contrast, \textsc{Hokie-LM} introduces the \textbf{Zero-Token Latent MCTS Rollout Planner}, which performs multi-branch state rollouts entirely in continuous-discrete latent space $(\mathbf{h}, z)$ without emitting intermediate text tokens, achieving high reasoning depth at only \textbf{$1.25\times$ FLOPs}.

\paragraph{5. Machine Unlearning \& State Privacy Scrubbing.}
With the enactment of data privacy mandates (e.g., GDPR Right to Be Forgotten), machine unlearning has become a critical capability \citep{bourtoule2021machine,nguyen2022survey}. 
Existing unlearning techniques for Transformers rely on approximate gradient ascent, influence functions, or localized parameter editing (e.g., ROME \citep{meng2022locating}), which require minutes to hours of GPU computation and risk catastrophic forgetting of unrelated knowledge. 
In recurrent and state-space architectures, \textsc{Hokie-LM} establishes the first provably exact unlearning mechanism via the \textbf{Semantic Subspace Nullification Operator ($\mathbf{P}_\perp$)}, executing instantaneous linear-algebraic projection in $184.3\text{ ms}$ with mathematically guaranteed zero mutual information ($I \equiv 0$, Theorem~\ref{thm:unlearning}).
