\section{Experiments \& Empirical Analysis}
\label{sec:experiments}

We evaluate Hokie-LM across seven rigorous experimental axes designed to stress-test associative memory capacity, multi-hop reasoning efficiency, hardware serving scalability on NVIDIA H100 GPUs, semantic interpretability, component necessity, ultra-long-context active forgetting longevity, and adversarial robustness. All empirical metrics are directly measured from real PyTorch tensor execution pipelines and custom Triton GPU kernels on an NVIDIA H100 PCIe (80GB VRAM, CUDA 13.0).

\subsection{Multi-Query Associative Recall (MQAR up to 16k Scale)}
\label{sec:exp_mqar}

\paragraph{Experimental Protocol \& Setup.}

The dataset consists of synthetic key-value retrieval streams with a vocabulary size $V=8\text{,}192$. Each sequence contains $N_{\text{keys}} \in [16, 256]$ arbitrary key-value pairs distributed uniformly across the context horizon, followed by multiple associative lookup queries at sequence termination. We evaluate on $500$ test sequences per context length with model dimensions $d_{\text{model}}=128$, $d_{\text{state}}=16$, and $N_{\text{layers}}=2$.
