### 1.1 스칼라, 벡터, 행렬, 텐서의 물리적 의미

```
[ 스칼라 (Scalar) ]       [ 벡터 (Vector) ]          [ 행렬 (Matrix) ]              [ 3차원 텐서 (Tensor) ]
     s = 3.14           v = [ 0.2 ]              M = [ 0.2  0.8 ]             T = [ [ 0.2  0.8 ],
                            [ 0.9 ]                  [ 0.5  0.1 ]                   [ 0.5  0.1 ] ],
                            [ 0.1 ]                  [ 0.7  0.4 ]                 [ [ 0.9  0.3 ],
                                                                                    [ 0.4  0.6 ] ]
 (단일 측정값)         (한 단어의 의미 좌표)      (단어들의 관계/지식 맵)        (여러 배치/레이어의 상태)
```

1. **스칼라 (Scalar, 예: `γ_t`, `β`, `τ`)**: 
   - 그냥 숫자 1개입니다. 예를 들어 "서프라이즈 점수 = `2.4`", "온도 = `0.5`"처럼 세기나 크기를 나타냅니다.
2. **벡터 (Vector, 보통 소문자 `x_t`, `u`, `z`)**:
   - 숫자들의 1차원 목록입니다. AI에서는 **"한 단어나 개념이 가진 성질들의 좌표"**를 의미합니다.
   - 예: `[사과] = [달콤함: 0.9, 빨간색: 0.8, 컴퓨터: 0.0]`, `[애플회사] = [달콤함: 0.0, 빨간색: 0.1, 컴퓨터: 0.95]`
   - `d_model = 1024`라는 것은 하나의 단어를 1024차원의 공간 좌표로 표현한다는 뜻입니다.
3. **행렬 (Matrix, 보통 대문자 `A`, `B`, `W`, `P_⊥`)**:
   - 숫자들이 직사각형 격자(2차원)로 배열된 것입니다. 
   - 벡터를 입력받아 다른 벡터로 변환하는 **"변환 기계(Transform Engine)"** 또는 **"기억 저장소(Memory Table)"** 역할을 합니다.
4. **텐서 (Tensor, 보통 `h_t ∈ R^(B × d_model × d_state)`)**:
   - 3차원 이상의 다차원 배열입니다. 배치(Batch) × 특징 차원 × 상태 차원 등을 한 번에 묶은 것입니다.

### 1.2 내적(Dot Product, `u^T v` 또는 `⟨u, v⟩`)의 본질: "그림자 투영과 유사도"

> **수식 표현**: `u^T v = ⟨u, v⟩ = Σ (u_i · v_i) = ||u|| · ||v|| · cos(θ)`

```
         v
        ^
       /|
      / |
     /  | (수직 수선의 발)
    /   |
   +----+--------> u
     [ u 위에 드리운 v의 그림자 길이 ] = (u^T v) / ||u||
```

- **직관적 의미**:
  1. 두 벡터 `u`와 `v`가 **"얼마나 같은 방향을 바라보고 있는가(유사도, Similarity)"**를 측정합니다.
  2. `u`와 `v`의 방향이 완전히 같으면 (`θ = 0°`, `cos(0)=1`) 내적값은 최대가 됩니다.
  3. `u`와 `v`가 서로 수직(직교)이면 (`θ = 90°`, `cos(90)=0`) **내적값은 정확히 `0`**이 됩니다.
  4. 본 논문에서 프라이버시 삭제를 증명할 때 `⟨v_secret, h*⟩ = 0`이 나오는 이유는, 지워야 할 비밀 방향(`v_secret`)과 모델의 남은 기억(`h*`)이 **서로 완벽히 수직(직교)이라 어떤 그림자도 남지 않기 때문**입니다.

---

### 1.3 외적(Outer Product, `u v^T`)의 본질: "메모리 행렬에 기억 쓰기"

> **수식 표현**:  
> `u ∈ R^N, v ∈ R^M` 일 때, `u v^T ∈ R^(N × M)` (행렬이 됨)

```
       v^T = [ v1    v2    v3 ]
 u = [ u1 ]  [ u1*v1 u1*v2 u1*v3 ]
     [ u2 ]  [ u2*v1 u2*v2 u2*v3 ]  <--- N x M 크기의 새로운 지식 행렬 생성!
     [ u3 ]  [ u3*v1 u3*v2 u3*v3 ]
```

- **직관적 의미**:
  - 내적(`u^T v`)은 두 벡터를 곱해 **숫자 1개(스칼라)**를 만들지만,
  - 외적(`u v^T`)은 두 벡터를 곱해 **거대한 행렬(Matrix)**을 만듭니다.
  - 연상 기억(Associative Memory)에서 Key 벡터 `k`와 Value 벡터 `v`를 연결하여 메모리 행렬 `M`에 저장할 때 `M ← M + v k^T` 형태로 씁니다.

---

### 1.4 직교(Orthogonality)와 영공간(Null Space): "완벽한 소거의 비밀"

```
                    y축 (Secret Subspace: 비밀 정보 축)
                     ^
                     |   * [비밀 벡터 v_secret]
                     |   
                     |   
  -------------------+----------------------------> x축 (Orthogonal Complement: 일반 지식 축)
                     |
                     |   * [소거 후 남은 상태 h* = P_⊥ · h]
                     |
                     (y축 성분이 정확히 0이 됨!)
```

1. **직교(Orthogonal, `⊥`)**: 두 벡터가 `90°`를 이루어 서로 전혀 영향을 주지 않는 상태입니다.
2. **사영(Projection, `P`)**: 어떤 벡터를 특정 평면 위에 빛을 비춰 그림자를 떨어뜨리는 연산입니다.
3. **직교 여공간 사영(Orthogonal Complement Projection, `P_⊥ = I - P`)**:
   - 전체 공간(`I`)에서 "비밀 정보가 사는 공간(`P`)"을 **통째로 빼버리는 연산자**입니다.
   - 어떤 기억 `h`에 `P_⊥`를 곱하면, 비밀 정보 방향 성분은 **마치 가위로 오려낸 것처럼 정확히 `0`**이 되고, 비밀과 무관한 일반 지식은 `100%` 그대로 남습니다.

### 1.5 행렬 노름(Norm)과 스펙트럼 반지름(`ρ(A)`): "시스템이 폭발하지 않는 원리"

1. **벡터 노름 (`||x||`)**: 벡터의 물리적 길이입니다. 예: 2차원에서 `√(x_1^2 + x_2^2)`.
2. **행렬 노름 (`||A||`)**: 행렬 `A`가 벡터를 최대 몇 배까지 잡아 늘릴 수 있는가의 배율입니다.
3. **스펙트럼 반지름 (`ρ(A)`)**: 행렬 `A`의 고윳값(Eigenvalue) 중 가장 큰 절댓값입니다.
   - 만약 `ρ(A) ≥ 1` 이면: 루프를 돌 때마다 상태가 눈덩이처럼 불어나 **무한대로 폭발(Explosion)**합니다.
   - 만약 `ρ(A) ≤ 1 - ε < 1` 이면: 루프를 `K`번 돌릴 때마다 `(1-ε)^K → 0`으로 줄어들어 **시스템이 스스로 진정(Contraction, 수축)**됩니다.

### 1.6 정보이론 3대 기호: 엔트로피, KL 발산, 상호정보량

1. **엔트로피 (`H(X)`)**:
   - 확률 변수 `X`가 가진 **"불확실성(깜짝 놀람의 잠재량)"**입니다. 동전 던지기는 불확실성이 높고, 항상 1만 나오는 주사위는 엔트로피가 0입니다.
2. **KL 발산 (`D_KL(q || p)`)**:
   - 두 확률분포 `q`와 `p` 사이의 **"정보적 괴리(놀라움의 크기, Surprise)"**입니다.
   - 내 뇌의 사전 예측(`p`)과 눈앞에 나타난 실제 단어(`q`)가 완벽히 일치하면 `D_KL = 0` (하나도 안 놀람).
   - 갑자기 엉뚱한 외계어 단어가 튀어나오면 `D_KL >> 0` (서프라이즈 폭발 → 메모리에 강하게 기록!).
3. **상호정보량 (`I(X; Y)`)**:
   - `Y`라는 변수를 관측했을 때, `X`에 대해 알게 되는 **"공유 정보의 양(비트 수)"**입니다.
   - `I(X; Y) = 0` 이라는 것은: `Y`를 아무리 현미경으로 뜯어보고 100층짜리 딥러닝으로 분석해도 **`X`에 대한 단 1비트의 단서도 얻을 수 없음(완벽한 독립, Absolute Zero-Leakage)**을 의미합니다.

# 제2장: Hokie-LM 아키텍처 핵심 수식 낱낱이 해부

논문의 Section 3(Methodology)에 등장하는 핵심 수식 체계를 변수 단위로 해부합니다.

```
                   [ 입력 토큰 x_t ]
                          │
         ┌────────────────┴────────────────┐
         ▼                                 ▼
[ 사후 네트워크 q_φ ]             [ 사전 네트워크 p_θ ]
q(z_t | h_{t-1}, x_t)            p(z_t | h_{t-1})
         │                                 │
         └────────────────┬────────────────┘
                          ▼
            [ KL 서프라이즈 계산 ]
            γ_t = D_KL( q || p )
                          │
          ┌───────────────┴───────────────┐
          │ (Salience Boost)              │ (Eviction Inhibit)
          ▼                               ▼
 [ 입력 증폭: (1 + σ(W_s · γ_t)) ]   [ 망각 억제: E_t → 0 ]
          │                               │
          └───────────────┬───────────────┘
                          ▼
             [ 연속-이산 SSM 듀얼 루프 ]
     h_t = A_t · h_{t-1} + B_t · [e(x_t); z_t]
                          │
                          ▼
             [ CAFE 영공간 소거 (P_⊥) ]
                 h*_t = P_⊥ · h_t
```

### 2.1 듀얼 루프 상태 방정식 (식 1 ~ 4)

> **[식 1: 사전 예측 (Prior Prediction)]**  
> `p_θ(z_t | h_{t-1}) = Categorical(Softmax(W_prior · h_{t-1}))`  
>
> **[식 2: 사후 인식 (Posterior Recognition)]**  
> `q_φ(z_t | h_{t-1}, x_t) = Categorical(Softmax(W_post · [h_{t-1}; e(x_t)]))`  
>
> **[식 3: 정보적 서프라이즈 (KL Surprise Metric)]**  
> `γ_t = D_KL( q_φ(z_t | h_{t-1}, x_t) || p_θ(z_t | h_{t-1}) )`  
>
> **[식 4: 상태 갱신 (State Update Equation)]**  
> `h_t^raw = A_t^active · h_{t-1} + B_t · ( (1 + σ(W_s · γ_t)) · [e(x_t); z_t] )`

#### 🔍 각 변수의 의미:
- `h_{t-1} ∈ R^(d_model × d_state)`: 과거 `t-1` 시점까지의 모든 연속적인 문맥이 압축된 **연속형 SSM 상태** (크기: `17.0 KB`).
- `x_t ∈ {1, ..., V}`: 현재 들어온 입력 단어(토큰) 번호.
- `e(x_t) ∈ R^d_model`: 입력 단어 `x_t`를 다차원 벡터 공간에 매핑한 **임베딩 벡터**.
- `p_θ(z_t | h_{t-1})`: 과거 문맥(`h_{t-1}`)만 보고 "다음에 어떤 개념(`z_t`)이 올까?" 하고 뇌가 **스스로 상상(예측)한 사전 확률분포**.
- `q_φ(z_t | h_{t-1}, x_t)`: 과거 문맥(`h_{t-1}`)에 더해 실제 눈앞의 단어(`e(x_t)`)까지 보고 "아, 이 단어는 이런 뜻이구나!" 하고 **정확히 인식한 사후 확률분포**.
- `z_t ∈ Δ^(32 × 32)`: 32개 범주 각각에서 32개 클래스 중 하나를 선택하는 **이산 범주형(Categorical) 잠재 변수** (뇌의 고수준 개념 심볼).
- `γ_t ≥ 0`: 사후 분포(`q_φ`)와 사전 분포(`p_θ`) 간의 KL 발산으로 측정한 **"정보적 새로움/놀라움(Surprise)"**.
- `σ(W_s · γ_t) ∈ (0, 1)`: 서프라이즈 점수 `γ_t`를 Sigmoid 함수를 거쳐 `0 ~ 1` 사이의 게이트 가중치로 변환한 것.
- `[e(x_t); z_t]`: 표면 단어 벡터 `e(x_t)`와 고수준 개념 벡터 `z_t`를 세로로 이어 붙인(Concatenate) 통합 표현.

---

### 2.2 인지 능동 망각 엔진 (CAFE) 수식 체계

> **[수명 감쇄 계수 벡터]**  
> `Ω = [ 0.05 · 1^(d_pers) (영구 60%),  1.0 · 1^(d_work) (작업 30%),  30.0 · 1^(d_scratch) (스크래치 10%) ]^T`  
>
> **[동적 전이 행렬]**  
> `A_t^active = exp( -Δ_t · A ⊙ (1 + Ω ⊙ E_t) )`  
>
> **[영공간 소거 및 상태 투영]**  
> `P_⊥ = I - (v_obs · v_obs^T) / ||v_obs||^2`  
> `h_t = P_⊥ · h_t^raw`

#### 🔍 각 변수의 의미:
- `Ω` (오메가): 상태 메모리 채널들의 **수명 감쇄 계수 벡터**.
  - 영구 채널 (`60%`): `ω = 0.05 →` 거의 영원히 잊지 않고 보존 (시스템 프롬프트, 인물 페르소나).
  - 작업 채널 (`30%`): `ω = 1.0 →` 현재 대화 문맥 유지.
  - 스크래치패드 (`10%`): `ω = 30.0 →` 계산이 끝나면 즉시 휘발 (단기 암산, 일회용 툴 로그).
- `E_t ∈ [0, 1]`: **능동 방출(Eviction) 게이트**. 새로운 중요한 정보가 들어오면(`γ_t ↑`) `E_t → 0`이 되어 망각을 차단하고, 토픽이 바뀌면 `E_t → 1`이 되어 잡음을 방출.
- `P_⊥`: 특정 변수(`v_obs`)를 모델의 모든 기억에서 흔적도 없이 도려내는 **영공간 직교 투영 행렬**.

# 제3장: 정리 1 — 서프라이즈 게이팅에 의한 온라인 압축 리그렛 최소화 (Theorem 1)

---

### 3.1 정리의 공식 문장 및 수식

> **Theorem 1 (Variational Regret Bound with Surprise Gating)**  
> 시퀀스 데이터 분포 `p_data(x_{1:T})`가 `M = |T*|`개의 의미적 변곡점(Change-points) `T* = {t_1*, ..., t_M*}`을 가진다고 하자.  
> 서프라이즈 변조 갱신 `u_eff = (1 + σ(W_s · γ_t)) · u_t` (단, `γ_t = D_KL(q_φ || p_θ)`) 하에서, 모델의 누적 시퀀스 예측 리그렛(Cumulative Regret) `R_T`는 다음 상계를 만족한다:
>
> `R_T = Σ_{t=1}^T [ -log P(x_t | h_{t-1}) - min_{θ*} E[ -log P_{θ*}(x_t | x_{<t}) ] ] ≤ O( |T*| · d_model · log T + Σ_{t ∉ T*} γ_t )`

---

### 3.2 모든 기호와 변수의 1:1 상세 정의표

| 기호 / 수식 | 수학적 정의 | 단위 / 형태 | 물리적·직관적 의미 |
| :--- | :--- | :--- | :--- |
| `T` | 시퀀스 전체 길이 | 자연수 (`T ∈ N`) | 전체 토큰 수 (예: 16,384 토큰, 100,000 토큰) |
| `x_{1:T} = [x_1, ..., x_T]` | 입력 토큰 시퀀스 | 단어 ID 배열 | 문장 또는 문서 전체의 단어 나열 |
| `T* = {t_1*, ..., t_M*}` | 변곡점 집합 | 시점 인덱스 집합 | 새로운 주제가 시작되거나 중요한 사건이 터진 시점들 |
| `M = |T*|` | 변곡점의 총 개수 | 자연수 (`M << T`) | 10만 단어 중 진짜 중요한 사건이 일어난 횟수 (예: 100번) |
| `-log P(x_t | h_{t-1})` | 온라인 음의 로그 우도 | 실수 (`≥ 0`, nats/bits) | `17.0 KB` 상수 상태 `h_{t-1}`만 보고 다음 단어 `x_t`를 예측할 때 느끼는 **당혹감(Loss)** |
| `min_{θ*} E[-log P_{θ*}(x_t | x_{<t})]` | 전지전능한 이상적 오라클의 Loss | 실수 (`≥ 0`) | 무한한 KV 캐시를 다 보고 사후에 구한 **이론상 완벽한 최적의 Loss** |
| `R_T` (리그렛, Regret) | 두 손실(Loss)의 누적 차이 | 실수 (`≥ 0`) | **"상수 메모리로 압축해서 예측하느라 완벽한 오라클에 비해 누적해서 손해 본 총량"** |
| `d_model` | 은닉층 차원 수 | 자연수 (`512` 또는 `1024`) | 단어 표현의 벡터 차원 수 |
| `Σ_{t ∉ T*} γ_t` | 평온한 구간에서의 서프라이즈 합 | 실수 (`≥ 0`) | 주제가 안 바뀌는 평온한 일상 구간에서의 미세 잔여 오차 |

---

### 3.3 '리그렛(Regret)'이란 무엇이며 왜 sub-linear(`log T`)여야 하는가?

- **비유**: 여러분이 100권짜리 책을 읽으면서, 책 전체를 통째로 외우는 천재(오라클, Transformer)와 손바닥만 한 메모지 1장(`17.0 KB`)에 요약하며 읽는 여러분(Hokie-LM)의 시험 점수 차이를 비교합니다.
- 만약 여러분의 요약 방식이 엉망이면, 책이 100권으로 늘어날 때 손해 보는 점수 차이(`R_T`)는 책 권수 `T`에 비례하여 `O(T)`로 선형 폭발(Linear Explosion)합니다. → **기억 상실 발생!**
- 하지만 Theorem 1은 우리의 손해 총량이 오직 **"주제가 바뀐 횟수 `M`"**에만 비례하고, 시간 `T`에 대해서는 매우 완만한 `log T`로만 증가함을 증명합니다 (`O(M · log T)`).
- 따라서 시간당 평균 리그렛은 `lim_{T → ∞} (R_T / T) = 0`이 되어, **아무리 긴 글을 읽어도 상수 메모리 `17.0 KB`로 인한 정보 손실이 0으로 수렴함**을 수학적으로 보장합니다.

---

### 3.4 증명(Proof)의 단계별 쉬운 해설

1. **구간 분할 (Regime Partitioning)**:
   전체 `1 ~ T` 시간을 변곡점 `t_k*`를 기준으로 `M+1`개의 평온한 구간(Stationary Epochs)으로 나눕니다.
2. **평온한 구간 (`t ∉ T*`)에서의 오차 유계**:
   주제가 안 바뀌는 동안에는 다음 단어가 예측 가능하므로 서프라이즈 `γ_t = D_KL ≤ ε`입니다. 상태 갱신이 안정적이므로 이 구간의 누적 오차는 `Σ γ_t`로 제한됩니다.
3. **변곡점 (`t ∈ T*`)에서의 정보 흡수**:
   새로운 중요한 정보가 등장하면 서프라이즈 `γ_t >> 0`가 스파이크를 칩니다. 이때 식 (4)의 증폭 계수 `(1 + σ(W_s · γ_t))`가 즉각 작동하여 새로 들어온 핵심 정보를 `h_t`에 강하게 새깁니다. 이 전환 비용은 정보이론적 MDL(Minimum Description Length) 원리에 의해 `O(d_model · log T)`로 유계됩니다.
4. **합산**: `M`개의 변곡점 비용과 평온 구간 비용을 합치면 정리 1의 최종 상계 `O(M · d_model · log T + Σ γ_t)`가 완성됩니다. ■ [Q.E.D.]

# 제4장: 정리 2 — Hurwitz SSM 안정성 하에서의 유계 잠재 드리프트 (Theorem 2)

---

### 4.1 정리의 공식 문장 및 수식

> **Theorem 2 (Bounded Latent Drift under Hurwitz SSM Stability)**  
> 이산화된 시스템 행렬의 스펙트럼 반지름이 `ρ(A_t) ≤ 1 - ε` (단, `ε ∈ (0, 1)`)을 만족하는 대각 Hurwitz 안정성을 가진다고 가정하자.  
> `L_z = ||B_z||`를 잠재 변환의 립시츠 연속 상수(Lipschitz constant)라 하자.  
> 임의의 초기 상태 `h_t`와 임의의 무제한 롤아웃 깊이 `K ≥ 1`에 대하여 다음 부등식이 성립한다:
>
> `||h_{t+K}|| ≤ (1 - ε)^K · ||h_t|| + [ (1 - (1 - ε)^K) / ε ] · L_z · ||z_max||`
>
> 나아가, 롤아웃 깊이가 무한대로 갈 때의 점근적 상태 드리프트(Asymptotic Drift)는 엄격히 유계된다:
>
> `lim_{K → ∞} ||h_{t+K} - h_t|| ≤ (1 / ε) · L_z · ||z_max|| < ∞`

---

### 4.2 모든 기호와 변수의 1:1 상세 정의표

| 기호 / 수식 | 수학적 정의 | 단위 / 형태 | 물리적·직관적 의미 |
| :--- | :--- | :--- | :--- |
| `K` | 잠재 생각 롤아웃 깊이 | 자연수 (`K = 1, 2, ..., ∞`) | 텍스트 출력 없이 머릿속으로 시뮬레이션한 생각의 단계 수 |
| `h_t` | `t` 시점의 초기 상태 벡터 | 벡터 (`R^d_model`) | 생각을 시작하기 직전의 현재 기억 상태 |
| `h_{t+K}` | `K`단계 상상 후의 상태 벡터 | 벡터 (`R^d_model`) | 머릿속으로 `K`번 시뮬레이션한 미래의 생각 상태 |
| `A_t` | SSM 전이 행렬 (Transition Matrix) | 대각 행렬 (`R^(d × d)`) | 과거 상태를 다음 상태로 전달할 때의 감쇄/전이 연산자 |
| `ρ(A_t)` | 행렬 `A_t`의 스펙트럼 반지름 | 실수 (`0 < ρ < 1`) | 한 번 생각할 때 과거 기억이 줄어드는 감쇄율 (예: 0.95) |
| `ε` | 안정성 마진 (Stability Margin) | 실수 (`ε ∈ (0, 1)`) | 감쇄율이 1보다 얼마나 작은지를 나타내는 안전 마진 (`1 - ρ`) |
| `B_z` | 잠재 입력 투영 행렬 | 행렬 (`R^(d × d_z)`) | 개념 코드 `z`를 연속 상태 `h`로 주입하는 연결 행렬 |
| `L_z = ||B_z||` | 립시츠 상수 (Lipschitz Constant) | 실수 (`L_z > 0`) | 개념 `z`가 변할 때 상태 `h`가 최대 몇 배 변할 수 있는가의 민감도 |
| `z_max` | 잠재 심볼 벡터의 최댓값 | 벡터 (`||z|| ≤ 1`) | Gumbel-Softmax에 의해 확률 심플렉스(`Σ z_i = 1`) 내로 제한된 개념 크기 |
| `||h_{t+K} - h_t||` | 생각의 총 이동 거리 (Drift) | 실수 (`≥ 0`) | 처음 생각에서 얼마나 멀리 떨어져 나갔는가의 거리 |

---

### 4.3 '수축 사상(Contraction Mapping)'과 'Hurwitz 안정성'의 직관

```
   [ 초기 상태 h_t ]
         │ (x 0.9)
         ▼
   [ 1단계 h_{t+1} ] ───> + 새 생각 주입 (크기 1.0)
         │ (x 0.9)
         ▼
   [ 2단계 h_{t+2} ] ───> + 새 생각 주입 (크기 1.0)
         │
         ▼
       ..... (K번 반복)
         │
         ▼
   [ 수렴 한계선: 1.0 / (1 - 0.9) = 10.0 이하로 절대 못 벗어남! ]
```

- **직관적 비유 (용수철과 감쇄기)**:
  - Hurwitz 안정성이란 진동하는 용수철에 끈적한 오일 댐퍼(감쇄기)를 달아놓은 것과 같습니다.
  - 아무리 밖에서 발로 차고 흔들어도(새로운 생각 `z`를 계속 집어넣어도), 오일 저항(`1 - ε`) 때문에 시스템은 특정 반경 밖으로 튕겨 나가지 못합니다.
  - 이것이 수학에서 말하는 **바나흐 고정점 정리(Banach Fixed Point Theorem / Contraction Mapping)**의 원리입니다.

---

### 4.4 깊은 생각(Rollout `K → ∞`)을 해도 모델이 왜 미쳐 날뛰지 않는가?

- 기존 생성 모델의 최대 공포: "머릿속으로 계속 상상만 돌리면(Ungrounded Rollout), 오차가 누적되어 결국 외계어를 뱉거나 헛소리(Hallucination Explosion)를 하지 않을까?"
- **Theorem 2의 철퇴**:
  - `K → ∞`로 갈 때, 초기 상태 `h_t`의 영향력은 `(1 - ε)^K → 0`으로 완전히 소멸합니다.
  - 새로 들어오는 생각들의 누적 합은 등비급수 `Σ_{k=0}^∞ (1 - ε)^k = 1 / ε`으로 **정확히 상한선에 수렴**합니다.
  - 따라서 100번, 10,000번 깊은 생각을 돌려도 모델의 잠재 상태는 안전한 구체(Attractor Basin) 안에 갇혀 있어 환각 폭발이 원천적으로 불가능합니다.

---

### 4.5 증명(Proof)의 단계별 쉬운 해설

1. **재귀 전개 (Recurrence Unrolling)**:
   `h_{t+K} = A^K · h_t + Σ_{k=0}^{K-1} A^k · B_z · z_{t+K-k}`
2. **삼각 부등식 및 노름 성질 적용**:
   `||h_{t+K}|| ≤ ||A||^K · ||h_t|| + ||B_z|| · ||z_max|| · Σ_{k=0}^{K-1} ||A||^k`
3. **스펙트럼 상계 `ρ(A) ≤ 1 - ε` 대입**:
   등비수열의 합 공식 `Σ_{k=0}^{K-1} (1 - ε)^k = (1 - (1 - ε)^K) / ε`을 적용합니다.
4. **극한 취하기 (`K → ∞`)**:
   `(1 - ε)^K → 0` 이므로, `||h_{t+K}|| ≤ (L_z · ||z_max||) / ε < ∞` 로 엄격히 유계됩니다. ■ [Q.E.D.]

# 제5장: 정리 3 — 트랜스포머의 교란 포화 vs CAFE의 상수 SNR (Theorem 3)

---

### 5.1 정리의 공식 문장 및 수식

> **Theorem 3 (Distractor Saturation in Transformers vs. Constant SNR in CAFE)**  
> 시퀀스 길이 `T` 내에 유의미한 정보 토큰 `N_sal`개와 무의미한 교란 토큰(Distractors) `T - N_sal`개가 섞여 있다고 하자.  
> Softmax Attention 하에서 신호 대 잡음비(Signal-to-Noise Ratio)는 시퀀스 길이가 증가함에 따라 `0`으로 붕괴한다:
>
> `lim_{T → ∞} SNR_Transformer(T) = lim_{T → ∞} ( E[Z_salient] / E[Z_distractor] ) = 0  (Catastrophic Distraction)`
>
> 반면, 다중 스케일 채널 분할 `Ω` 및 능동 방출 `E_t`를 적용한 CAFE 하에서는 교란 상태 에너지가 지수적으로 억제되고 유의미한 채널의 전이 계수는 `A_sal^active ≈ 1`을 유지하여, SNR이 엄격한 양수 상수로 하한 유계된다:
>
> `lim_{T → ∞} SNR_CAFE(T) ≥ ( N_sal · ||B_sal|| ) / ( [ 1 / (1 - ρ(A_dist)) ] · ||B_dist|| ) ≥ C_min > 0`

---

### 5.2 모든 기호와 변수의 1:1 상세 정의표

| 기호 / 수식 | 수학적 정의 | 단위 / 형태 | 물리적·직관적 의미 |
| :--- | :--- | :--- | :--- |
| `N_sal` | 핵심 정보 토큰의 수 (Salient) | 자연수 (상수) | 기억해야 할 진짜 중요한 단어 수 (예: 비밀번호, 핵심 룰 10개) |
| `T - N_sal` | 잡음 교란 토큰의 수 (Distractor) | 자연수 (`T → ∞`) | 중간에 지나가는 수만 개의 잡담, 일회용 로그, 무의미한 단어들 |
| `Z_salient` | 핵심 정보에 배정된 어텐션 점수 | 실수 (`≥ 0`) | 모델이 중요한 정보에 쏟는 관심의 총합 |
| `Z_distractor` | 교란 잡음에 분산된 어텐션 점수 | 실수 (`≥ 0`) | 모델이 엉뚱한 잡음에 낭비하는 관심의 총합 |
| `SNR(T)` | 신호 대 잡음비 (Signal-to-Noise Ratio) | 무차원 비율 (또는 `dB`) | **"잡음 대비 진짜 핵심 기억이 얼마나 또렷하게 살아있는가?"** |
| `A_sal^active` | 핵심 채널의 보존 계수 | 실수 (`≈ 1.0`) | CAFE 영구 채널(`ω = 0.05`)에서 핵심 정보가 안 지워지고 유지되는 비율 |
| `ρ(A_dist)` | 교란 채널의 감쇄율 | 실수 (`< 1.0`) | CAFE 스크래치패드 채널(`ω = 30.0`)에서 잡음이 빠르게 날아가는 비율 |
| `C_min` | CAFE가 보장하는 최소 SNR 바운드 | 양의 실수 (`C_min > 0`) | 100만 단어가 지나도 절대 깨지지 않는 최소 기억 선명도 (실측 `24.7 dB`) |

---

### 5.3 트랜스포머 Softmax의 치명적 결함: 왜 `SNR → 0`으로 망가지는가?

```
[ 트랜스포머의 어텐션 소프트맥스 분모 ]
 분모 = exp(중요정보 1) + exp(중요정보 2) + exp(잡음 1) + exp(잡음 2) + ... + exp(잡음 10,000)
                                      └──────────────────────────────────────────────┘
                                          잡음 1만 개가 쌓이면 분모가 무한대로 폭발!
                                          결과: 중요정보 1개의 비중 = 1 / 10,000 → 0%로 희석!
```

- Softmax 함수는 모든 입력에 대해 `exp(x) > 0` (엄격한 양수)를 출력합니다.
- 즉, 아무리 쓸모없는 쓰레기 토큰이라도 어텐션 가중치를 최소 `0.0001`이라도 가져갑니다.
- 시퀀스 길이 `T`가 1만, 10만으로 길어지면, 잡음 토큰 수천 개가 가져가는 가중치의 합(`Σ exp`)이 분모를 장악하여, **정작 10만 단어 전에 정의한 시스템 프롬프트의 어텐션 가중치가 `0`으로 희석**되어 버립니다. (Context Rot / Catastrophic Distraction 발생!)

---

### 5.4 CAFE는 어떻게 100,000 토큰 후에도 `SNR ≥ C_min > 0`을 유지하는가?

- **CAFE의 비결: 채널 격리 + 능동 망각**:
  1. 핵심 룰은 영구 채널(`Ω_pers`)에 넣어 감쇄율 `A_sal ≈ 1.0`으로 영구 락을 겁니다.
  2. 일회용 잡음은 스크래치 채널(`Ω_scratch`)에 넣어 들어오자마자 `A_dist << 1`로 광속 감쇄시켜 버립니다.
  3. 잡음이 아무리 `T → ∞`로 쏟아져도, 감쇄 등비급수 공식에 의해 잡음의 총에너지는 `[ 1 / (1 - ρ(A_dist)) ] · ||B_dist||`라는 **작은 유한한 값으로 상한**이 걸립니다.
  4. 따라서 분자(핵심 기억)는 보존되고 분모(잡음)는 유계되므로, `SNR ≥ C_min = 24.7 dB`가 영원히 평평하게 유지됩니다.

---

# 제6장: 정리 4 (보안 정리 1) — 모델 출력값 역추적 불가능성 (Theorem on Model Inversion Hardness)

---

### 6.1 트랜스포머는 왜 출력값으로 프롬프트를 털릴 수 있는가?

> **[트랜스포머의 편미분 유출식]**  
> `∂y_t / ∂e_i = α_{t,i} · W_head · (∂LN / ∂h_t) · W_O^T · W_V^T + O( ∂α_{t,i} / ∂e_i ) ≠ 0`

- 트랜스포머는 KV 캐시에 과거 모든 단어 `x_i`의 임베딩 `e_i`를 압축 없이 날것 그대로 들고 있습니다.
- 따라서 출력 단어 `y_t`에서 입력 단어 `e_i`로의 편미분 그래디언트(`∂y_t / ∂e_i`)가 **항상 0이 아닌 유의미한 값**을 갖습니다.
- 공격자는 출력 확률값만 보고 역전파 경사하강법(`argmin ||M(e) - y||^2`)을 돌리면, **사용자가 처음에 입력한 비밀 프롬프트를 고스란히 복원**해 낼 수 있습니다.

---

### 6.2 Hokie-LM의 다대일(Many-to-One) 압축과 NP-Hard 비선형 게이팅 증명

```
[ 입력 공간: V^L (경우의 수 50,000^16,384 = 무한대) ]
                   │
                   ▼  (손실 압축 매핑 F)
[ 상태 공간: R^(d_model x d_state) (고정된 17.0 KB 버퍼) ]
```

> **Theorem on Inversion Hardness**  
> 시퀀스 길이 `L > (d_state · d_model) / log2 |V|`에 대하여, 동일한 상태 `h_t`를 만들어내는 원본 입력 텍스트의 가짓수(Pre-image Set 크기)는 다음과 같다:
>
> `|F^(-1)(h_t)| ≥ |V|^( L - (d_model · d_state) / log2 |V| ) >> 1`

- **직관적 설명**:
  - `16,384` 단어의 엄청난 정보량을 단 `17.0 KB`의 고정된 상태 공간에 욱여넣었기 때문에, **동일한 상태를 만들어내는 가짜 입력 문장이 50,000^15,000개 이상 존재**합니다 (비둘기집의 원리).
  - 게다가 최종 출력단에 `y_t = (h_t · C_t + D · x_t) ⊙ SiLU(z_t)` 라는 고도의 비선형 아다마르 곱(Hadamard Product)이 걸려 있어, 수많은 가짜 극솟값(Spurious Local Minima)이 생겨납니다.
  - 따라서 공격자가 출력값을 아무리 역공학해도 원본 프롬프트를 수학적으로 특정해 내는 것은 **NP-Hard (계산적으로 불가능)**합니다.

---

# 제7장: 정리 5 (보안 정리 2) — 영공간 직교 투영에 의한 완전 프라이버시 소거 (Theorem on Zero-Leakage)

---

### 7.1 정리의 공식 문장 및 수식

> **Theorem (Zero Information Leakage under Arbitrary Non-Linear Probing)**  
> 작동 메모리 상태 `h ∈ R^(d_model × d_state)`가 비밀 특징 부분공간 `span(V)`에 속하는 비밀 벡터 `v_secret`을 포함한다고 하자.  
> 영공간 사영 연산자 `P_⊥ = I - V^T (V V^T)^(-1) V`를 적용한 소거 상태 `h* = P_⊥ · h`는 다음을 만족한다:
>
> `⟨v_secret, h*⟩ = v_secret^T · ( I - V^T (V V^T)^(-1) V ) · h = 0`
>
> 결과적으로, 임의의 파라미터화된 적대적 심층 비선형 프로브 `ψ_φ: R^(d_model × d_state) → Y`에 대하여, 비밀 라벨 `Y_secret`과 소거된 표현 `h*` 사이의 섀넌 상호정보량(Mutual Information)은 **정확히 `0`**이다:
>
> `I(Y_secret; h*) ≡ 0    and    I(Y_secret; y_t(h*)) ≡ 0`

---

### 7.2 영공간 사영 행렬 `P_⊥` 유도 원리

```
1. 비밀 부분공간 기저 행렬: V (K개의 비밀 단어 임베딩을 행으로 쌓음)
2. 비밀 공간으로의 투영 행렬: P_parallel = V^T · (V · V^T)^(-1) · V
3. 비밀 공간을 도려낸 나머지 영공간: P_⊥ = I - P_parallel
```

- 어떤 벡터 `h`가 있을 때, 이를 "비밀과 평행한 성분(`h_parallel`)"과 "비밀과 수직인 성분(`h_⊥`)"으로 쪼갤 수 있습니다 (`h = h_parallel + h_⊥`).
- `P_⊥`를 곱하면:
  - `P_⊥ · h_parallel = (I - P_parallel) · h_parallel = h_parallel - h_parallel = 0` (비밀 성분 완벽 소멸!)
  - `P_⊥ · h_⊥ = h_⊥` (일반 지식 100% 보존!)

---

### 7.3 왜 내적 `⟨v_secret, h*⟩ = 0`이 되는가?

수학적으로 직접 전개해 보면 명쾌하게 증명됩니다:

```
⟨v_secret, h*⟩ = v_secret^T · P_⊥ · h
               = v_secret^T · ( I - V^T · (V · V^T)^(-1) · V ) · h
               = ( v_secret^T - [ v_secret^T · V^T · (V · V^T)^(-1) · V ] ) · h
               = ( v_secret^T - v_secret^T ) · h      <-- v_secret ∈ span(V) 이므로
               = 0 · h = 0
```

---

### 7.4 8계층 심층 딥러닝 프로브로 쥐어짜도 상호정보량 `I ≡ 0`인 이유

- **의문**: "선형 내적이 0이라도, 8계층 ResNet이나 MLP 같은 비선형 딥러닝 모델로 비선형 특징을 추출하면 비밀이 새어나오지 않을까?"
- **정보이론적 증명**:
  1. `h*` 안에서 `Y_secret` 방향의 신호 에너지는 진폭 자체가 `0`입니다.
  2. 따라서 비밀 라벨의 조건부 확률분포는 사전 확률분포와 완벽히 일치합니다: `p(h* | Y_secret = y) = p(h*)`.
  3. 섀넌 상호정보량 정의식에 대입하면:
     `I(Y_secret; h*) = H(h*) - H(h* | Y_secret) = H(h*) - H(h*) = 0`
  4. **데이터 처리 부등식 (Data Processing Inequality)**:
     아무리 강력한 1,000계층 인공신경망 `ψ_φ`를 후처리로 돌려도, 원본 데이터에 없는 정보량을 새로 만들어낼 수 없습니다 (`I(Y; ψ(h*)) ≤ I(Y; h*) = 0`).
  5. 따라서 적대적 프로브의 분류 정확도는 무조건 **`50.0%` (동전 던지기 찍기 수준)**로 고정되며, 단 1비트의 정보도 누출되지 않습니다! ■ [Q.E.D.]
